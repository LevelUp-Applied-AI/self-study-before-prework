# Self Study Resources for before Pre-Work 

If you’re feeling motivated and don’t want to wait for formal pre-work to begin, here are resources to help you prepare and keep your skills sharp. There are **no required submissions this week**. Git will be important for this course. If you are strong in Python but not in Git, skip to the Git & CLI section. 

---

## Coding Practice

### LeetCode

[https://leetcode.com/](https://leetcode.com/)

- Practice in **Python** and **SQL**
- Great for logic, edge cases, and structured thinking

---

### Codewars

[https://www.codewars.com/](https://www.codewars.com/)

- Do **6kyu and 7kyu problems**
- Focus on: Lists, Dictionaries, Loops, Functions

---

### CodeKata

[http://codekata.com/](http://codekata.com/)

- Short, repeatable programming exercises designed to build fluency through repetition and refinement.

---

### "Python Fingers"

[https://typing.io/lesson/python/mercurial/merge.py/1](https://typing.io/lesson/python/mercurial/merge.py/1)

- Improving typing speed reduces cognitive load while coding. This is becoming less and less relevant with AI coding assistance, but it is still a nice way to keep python fresh and a lightweight preparation exercise. 

---

## Git & CLI 

Strong Git skills will make this course go more smoothly for you! We'll use it for assignment submissions and collaboration. 

### GitMastery

[https://www.gitmastery.me/](https://www.gitmastery.me/)

- Structured Git exercises and branching practice.

---

### OverTheWire – Bandit

[https://overthewire.org/wargames/bandit/](https://overthewire.org/wargames/bandit/)

Fun command-line challenges that build Linux/CLI confidence.

---

### Codecademy – Learn Git

[https://www.codecademy.com/learn/learn-git](https://www.codecademy.com/learn/learn-git)

Step-by-step Git fundamentals course.

---

## Data & AI Foundations

### Kaggle Learn

[https://www.kaggle.com/learn](https://www.kaggle.com/learn)

- Recommended micro-courses: Python, Pandas, Intro to Machine Learning, Data Visualization

## 🎧 Podcasts for Industry Awareness

Listening helps you understand how AI is applied in the real world and will submerse you in the lingo of AI. 

Make a list of words you're not familiar with and google them or ask an LLM to explain it to you.

### ThursdAI

- Technical podcast about the latest model releases and happenings in AI. 

### Latent Space

- Technical conversations about LLMs, agents, and AI infrastructure.

### Lenny’s Podcast

- Less technical, product-oriented, but still excellent for understanding how AI features are built, shipped, and scaled in real companies.



There's a lot of other good content for learning on YouTube and podcast platforms. See what you can find!
